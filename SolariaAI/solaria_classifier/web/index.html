Where do I get a token?

Use the value of SOLARIA_STARTUP_TOKEN from the terminal where you started the service. Native mode prints a generated token if none was configured.

UNAUTHORIZED means the token does not match. The page is public; all API calls require authentication. Do not put tokens in URLs.
