Where do I get a token?

A token is a private password you create when starting the service. It must exactly match SOLARIA_STARTUP_TOKEN in the running container. It is not issued by a website.

In PowerShell, run these commands in the same terminal:

$env:SOLARIA_STARTUP_TOKEN = [guid]::NewGuid().ToString('N')
docker compose -f D:/Solaria/SolariaAI/compose.yaml up -d --build --wait
$env:SOLARIA_STARTUP_TOKEN

Copy the last command's output here. This replaces the container's previous token. Keep it private; do not paste tokens into URLs or screenshots.

If you already started it in this terminal, just run $env:SOLARIA_STARTUP_TOKEN. Native Python mode prints an automatically generated token in the startup terminal when none is configured.

UNAUTHORIZED means the token is missing or doesn't match. Opening /v1/health directly in a browser sends no bearer header; use Connect here instead.
