# Solaria

Welcome to the **Solaria** wiki!

Solaria is a Fabric mod for Minecraft 26.1.2. This wiki is the single place where every
block, item and mechanic added by the mod is documented.

It is written in the [Sinytra Wiki](https://moddedmc.wiki) format, which means it can be read

* on the web, and
* directly in game through the [Oracle Index](https://modrinth.com/mod/oracle-index) viewer.

## Where to start

* **Documentation** – guides that explain how to install the mod and how its systems work.
* **Content** – reference pages for the individual blocks, items and entities.

## Contributing

The wiki source lives in the `wiki/` directory of the mod repository. Pages are plain
Markdown (`.mdx`) files, so fixing a typo or adding a missing page is as easy as editing a
text file.
